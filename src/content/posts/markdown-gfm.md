本章收集常见的 GitHub 风格 Markdown 扩展。它们适合对比信息与记录进度，但不是所有 Markdown 渲染器都支持。

## 表格

表头与内容之间用分隔行；冒号控制对齐。表格适合简短内容，长段落请放在表格外。

```markdown
| 功能 | 状态 | 数量 |
| :--- | :---: | ---: |
| 文章 | 完成 | 3 |
| 图片 | 检查中 | 12 |
```

| 功能 | 状态 | 数量 |
| :--- | :---: | ---: |
| 文章 | 完成 | 3 |
| 图片 | 检查中 | 12 |

单元格内需要竖线时使用 `\|`，避免被当成新的列。

## 任务列表

使用 `- [ ]` 表示未完成，`- [x]` 表示已完成；方括号后保留空格。博客中的复选框用于展示状态，点击通常不会保存进度。

```markdown
- [x] 完成初稿
- [ ] 检查链接
- [ ] 发布文章
```

- [x] 完成初稿
- [ ] 检查链接
- [ ] 发布文章

## 删除线

```markdown
~~旧方案~~ 已替换为新方案。
```

~~旧方案~~ 已替换为新方案。

## 代码与其他扩展

行内代码用反引号包围，例如 `pnpm dev`。多行代码用三个反引号围起来，并在开头指定语言。下一章继续介绍代码块、行号、高亮和折叠。

公式、图表和提示框使用 Firefly 的独立插件，按“所属系列”选择对应章节即可。
