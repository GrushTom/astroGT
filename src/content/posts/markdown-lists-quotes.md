列表适合步骤和并列要点；引用用于标明引述内容。先选择合适的结构，再添加强调。

## 无序列表

使用 `-`、`*` 或 `+`，同一列表建议统一使用一种符号。

```markdown
- 安装工具
- 准备文章
- 预览效果
```

## 有序列表与嵌套

步骤使用数字加英文句点。嵌套内容应缩进到父项正文的位置；不要机械地给所有层级加相同数量的空格。

```markdown
1. 创建文章
   - 填写标题
   - 选择分类
2. 预览文章
   - 检查链接
   - 检查图片
```

列表项包含第二段时，在段落间空一行，并保持缩进。嵌入代码块也需要对齐到该列表项正文。

````markdown
1. 执行命令：

   ```sh
   pnpm dev
   ```

   打开终端显示的本地地址。
````

## 引用块

每行开头使用 `>`；嵌套引用增加一个 `>`。引用不自动标明来源，应附作者或链接。

```markdown
> 这里是引用内容。
>
> 这是引用中的第二段。
>> 这里是嵌套引用。
```

> 这里是引用内容。
>
> 使用引用表达引述关系，普通提醒可使用系列中的 Firefly 提示框。

## 分隔线

单独一行写三个或更多连字符、星号或下划线。建议前后留空行，避免 `---` 被理解为上一行的标题下划线。

```markdown
上一部分。

---

下一部分。
```
