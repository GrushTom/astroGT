本章介绍标题、段落、换行和强调。它们决定文字的基本层次，不需要额外插件。

## 标题

使用一到六个 `#`，后面加一个空格。按层级递进，不要为了改变字体大小而跳过层级。Firefly 已经显示文章标题，正文建议从 `##` 开始。

```markdown
## 安装方法
### Windows
### macOS
## 使用方法
```

## 段落与换行

段落之间空一行。源文件中仅按一次回车通常不会产生强制换行。

```markdown
这是第一段。

这是第二段。
```

需要在同一段内换行时，在行末留下两个空格再回车，也可以在 `.md` 中使用 `<br>`。编辑器可能清理行尾空格，因此排版后要预览。

```html
第一行<br>
第二行
```

## 强调

```markdown
*斜体*用于轻度强调。
**粗体**用于关键结论。
***粗斜体***同时应用两种样式。
```

*斜体*、**粗体**与***粗斜体***的区别如上。中文写作优先用星号，避免下划线与相邻文字产生解析歧义。

## 常见问题

- 标题没有生效：检查 `#` 后面是否有空格。
- 两段挤在一起：在两段之间补一个空行。
- 星号原样显示：检查前后数量是否对应，或是否放进了代码块。
- 不要用连续空格对齐文本；对比信息使用表格，程序内容使用代码块。
